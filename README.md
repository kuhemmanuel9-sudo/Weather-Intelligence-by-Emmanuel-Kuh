# Weather Intelligence

Weather Intelligence is a live weather dashboard designed and developed by Emmanuel Kuh. It brings forecasts, maps, charts, weather alerts, favorite locations, city comparisons, and simple planning guidance into one clean web page.

This project was built as a portfolio piece to show front end development, API integration, data visualization, responsive design, and practical JavaScript organization.

## What It Does

Weather Intelligence lets users search for a location, view current weather, check a 7 day forecast, compare cities, browse United States locations by state, and save favorite places in the browser.

The dashboard also includes weather analysis cards that turn raw forecast data into useful scores for outdoor comfort, travel, running, air quality, solar conditions, and storm risk.

## Features

1. Live current weather
2. 7 day forecast
3. Hourly and daily charts
4. Interactive map
5. NOAA weather alerts for United States locations
6. Air quality data where available
7. Browse all United States states and major cities
8. Use current location with browser permission
9. Compare two cities
10. Save favorite locations with local storage
11. Light and dark themes
12. Fahrenheit and Celsius support
13. Responsive layout for desktop and mobile

## How To Run It

Open `weather-intelligence-platform.html` in a browser.

live demo:https://kuhemmanuel9-sudo.github.io/Weather-Intelligence-by-Emmanuel-Kuh/

No build step is required. The project is a single HTML file, so the HTML, CSS, and JavaScript are all included in one place.

For the best experience, use a modern browser such as Chrome, Edge, Firefox, or Safari.

## Data Sources

Weather forecast data comes from Open Meteo.

Air quality data comes from Open Meteo Air Quality.

Weather alerts come from the National Weather Service for supported United States locations.

Map tiles come from OpenStreetMap contributors.

## Notes

This project runs fully in the browser. It does not use a backend, database, account system, or paid API key.

Some features depend on browser permissions or data availability. Current location requires the user to allow location access, and NOAA alerts are focused on United States locations.
